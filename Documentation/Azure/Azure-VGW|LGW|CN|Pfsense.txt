Azure RJServer Configuration

VGW, LGW, Connection Configuration

1.) Create VPN Gateway (VPN Gateway in Azure)

    Resource Group: rg-prod-rjserver
    Name: vgw-prod-rjserver-1
    Region: East US
    
    Gateway Type: VPN
    SKU: Basic
    Virtual Network: vnet-prod-rjserver-hub
    Subnet: Create GatewaySubnet (10.1.3.0/24)
    Type: Route-Based
    
    Public IP: pip-prod-rjserver-vgw (New)
    
 2.) Create Local Network Gateway (LGW) - (Represents the on-premises location configuration)
 
    Resource Group: rg-prod-rjserver
    Region: East US
    Name: lgw-prod-rjserver-homelab-pfsense
    Endpoint: IP address
    IP Address: Public Address for HomeLab
    Address Space: Internal Subnets (10.0.100.0/24, 10.0.200.0/24, 10.0.10.0/24)
    
    
 3.) Create VPN Connection
 
    Resource Group: rg-prod-rjserver
    
    Connection Type: Site-to-Site (IPSec)
    Name: cn-prod-rjserver-homelab-pfsense
    Region: East US
    
    
    Settings:
    
    Virtual Network Gateway: vgw-prod-rjserver-1
    Local Network Gateway: lgw-prod-rjserver-homelab-pfsense
    Authentication Method: PSK
    Shared Key: #####
    IKE Protocol: IKEv2
    IPSec/IKE Policy: Default
    DPD Timeout: 45
    Connection Mode: Default
    
 
 4.) Configure Pfsense in Homelab (On-Prem)
 
    4a.) Configure IPSec Phase 1:
    
        Remote Gateway: vgw-prod-rjserver-1 pip
        Description: VPN-Azure-to-Pfsense
        
        Authentitcation Method: PSK
        PSK: ####
        
        Phase 1: AES, 256 bits, SHA256, 2(1024 bit)
        
        Life Time: 10800
        
    4b.) Configure IPSec Phase 2:
    
        Local Network: LAN/Client Subnet
        Remote Network: Address Space of Hub (10.1.0.0/16)
        
        Phase 2 Proposal:
        Protocol: ESP
        Encryption Algorithm: AEA
        Hash Algorithm: SHA256
        PFS Key Group: 24 (2048(sub 256) bit)
        
    4c.) Configure Firewall Rule for IPSec Interface
    
    
    4d.) Connect P1 and P2 and test
    
    
 5.) Verify in Azure:
 
    cn-prod-rjsever-homelab-pfesne will show status as "Connected"
    
    Test connectivity to Pfsense from VM in Azure and vice versa
